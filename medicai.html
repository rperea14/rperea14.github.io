🚀 Platform Capabilities

Engineered for Modern Clinical Workflows

A comprehensive suite of tools built for speed, accuracy, compliance, and physician satisfaction.

🎙️

Real-Time Voice Scribing

Live audio streaming over WebSockets with Deepgram Nova-3 diarization, automatically separating physician and patient speech with millisecond turnaround.

📋

Dynamic Form Builder

Fully customizable drag-and-drop template builder for general intake, cardiology, neurology, pediatrics, and custom specialty forms.

⚙️

Granular AI Field Toggles

Organization admins can configure exactly which consultation fields should be auto-filled by AI summaries, dynamically syncing with form templates.

💊

Prescription & DIGEMID Catalog

Built-in drug library linked to official Peruvian DIGEMID database and CIE-10 (ICD-10) diagnosis codes with auto-dosage calculation and printable PDF layouts.

🏢

Multi-Tenant & Multi-Office

Role-Based Access Control (Super Admin, Organization Admin, Doctor, Receptionist) with multi-branch calendar sync and appointment scheduling.

🔒

Enterprise Security & Cloudinary

Secure audio storage, encrypted patient records, robust Better-Auth authentication, and automated backup mechanisms.

🛠️ Full-Stack Engineering

Modern Monorepo Architecture

High-performance, modular full-stack stack designed for horizontal scalability and production resilience.

Frontend Layer

React 18 + Vite + TypeScript

Tailwind CSS, Lucide Icons, Apollo Client (GraphQL), audio waveform visualizers, responsive mobile-first UI.

API & Real-time Layer

Node.js 22 + Apollo GraphQL

Express server, Socket.IO WebSockets for audio streaming, Better-Auth security, Prisma ORM.

Data & Persistence

PostgreSQL 17 + Prisma

Relational schema with organization multi-tenancy, dynamic forms JSON schemas, and automated seeding.

AI & Audio Engine

Deepgram Nova-3 + LLMs

Acoustic speech-to-text diarization paired with Claude / OpenAI models for structured clinical extraction.

Terminal: Quick Start with Docker
# 1. Clone repository and spin up full stack (PostgreSQL + Backend API + Frontend)
docker compose up -d --build

# 2. Apply Prisma database migrations
docker compose exec backend yarn workspace @testapp/backend migrate:deploy

# 3. Seed initial organization, roles, CIE-10 codes, and sample patient records
docker compose exec backend yarn workspace @testapp/backend seed:deploy

# Frontend App ready at: http://localhost:8080 | GraphQL API: http://localhost:3000/graphql
